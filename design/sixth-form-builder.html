What carries over from the Year 8 site, and what changes

Built as new lesson content and a few new components on the existing Astro project, not a separate app.

Kept from Navvy Builds

  • lesson.json content model, zod schema and checker
  • Live goals, hints one at a time, feedback that names the fix
  • Fake browser frame with the <title> on the tab
  • Deep links to levels for slides, localStorage progress
  • PDF report for Teams, now with exam marks
  • Navy and gold, pixel cube and snake, used more sparingly

New for Sixth Form

  • Three files in tabs: index.html, style.css, script.js
  • JavaScript running in the preview, with a console and alert() shown in the page
  • Fix, Trace and Exam task types alongside Build
  • Brief picker (four apps) in place of the hobby picker
  • Pseudocode ↔ JavaScript panel
  • Smaller type, denser layout, a code-editor look
