Counting with for loops

Make the computer repeat a job a set number of times, without copying and pasting.

About 15 minutes

1 The big idea

A for loop is like a coach saying "run 3 laps". The coach counts the laps for you, and i holds the lap number each time round.

2 Predict, then run

for i in range(1, 4):
    print("Round", i)
